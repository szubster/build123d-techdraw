# Export Formats

`build123d-techdraw` provides built-in exporters for SVG, vector PDF, and 1:1 DXF.

---

## 🎨 Interactive Dual-Theme SVG

SVGs generated by `build123d-techdraw` include dynamic CSS variables and an embedded client-side theme switcher.

```python
sheet.export_svg("blueprint.svg")
```

### Supported Themes

- **Dark Blueprint Mode:** Slate blue background (`#0d1929`), glowing cyan visible lines (`#64B5F6`), golden dimension text (`#FFE082`), and red-orange section hatchings (`#FF8A65`). Ideal for digital review and dark-mode displays.
- **Clean White ISO Mode:** Crisp white paper background (`#FFFFFF`), pure black visible lines (`#000000`), gray dashed hidden lines (`#757575`), and standard engineering typography. Ideal for high-contrast printing and regulatory archival.

Users viewing the SVG in any modern browser can toggle between themes simply by clicking the button in the top-right corner.

## 📄 Multi-Page Vector PDF Export

Export individual sheets or entire drawing packages into multi-page vector PDFs:

### Single Sheet PDF

```python
sheet.export_pdf("drawing.pdf")
```

### Multi-Page Drawing Booklet (`DrawingBooklet`)

```python
from build123d_techdraw import DrawingBooklet, DrawingSheet, SheetSize

booklet = DrawingBooklet(title="PRODUCT DRAWING PACKAGE")

sheet1 = DrawingSheet(sheet_size=SheetSize.A3_LANDSCAPE)
sheet1.set_title_block(title="ASSEMBLY OVERVIEW", sheet_num=1, num_sheets=2)

sheet2 = DrawingSheet(sheet_size=SheetSize.A4_PORTRAIT)
sheet2.set_title_block(title="BASE PLATE DETAIL", sheet_num=2, num_sheets=2)

booklet.add_sheet(sheet1)
booklet.add_sheet(sheet2)

# Export all sheets bundled into a single multi-page PDF
booklet.export_pdf("complete_package.pdf")
```

## 📐 1:1 DXF Flat Pattern Export

Export flat 2D profiles directly to DXF for laser cutting, plasma, waterjet, or CNC milling:

```python
# Export a 2D face, sketch, or projected view to 1:1 DXF
sheet.export_dxf("flat_pattern.dxf")
```
